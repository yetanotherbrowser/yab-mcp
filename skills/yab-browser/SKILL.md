# Yab, the user's browser

This file is only the way in. Run `yab guide` and follow what it says before using Yab.

- If `yab` isn't found, the user can add it in Yab › Settings › Developers.
- If `yab guide` shows a newer Skill version than 3, run `yab setup` and read it again.
